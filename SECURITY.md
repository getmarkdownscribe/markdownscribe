# Security policy

## Reporting a vulnerability

Email **<security@markdownscribe.com>**. Please do not open a public issue for security problems.

Include what you found, how to reproduce it and, if the problem involves an API call, its `request_id`. Never include a working API key: if a key was exposed, revoke it at [dashboard.markdownscribe.com](https://dashboard.markdownscribe.com/) first.

We will acknowledge your report and keep you informed until the fix ships.

## Scope

This repository contains the CLI and the SDK. Reports about the hosted API (`api.markdownscribe.com`) and the dashboard are welcome at the same address.

## Supported versions

Only the latest published version of each package receives fixes.
